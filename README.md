# RelayCraft (MinecraftHostApp)

Десктопное приложение (Windows, WPF/.NET 8) для игры в Minecraft компанией друзей **без выделенного сервера 24/7**. Друзья по очереди хостят мир с собственного компьютера, а приложение само синхронизирует мир, моды и настройки между хостами — так, будто это один и тот же постоянный сервер.

## Как это работает

1. Один из друзей создаёт сервер в приложении (версия Minecraft, загрузчик — Vanilla/Fabric, пароль входа).
2. Кто-то один нажимает **«Начать хостинг»** — приложение разворачивает и запускает сервер локально, остальные подключаются по IP (через playit.gg или локальную сеть).
3. Когда хост закончил играть, он жмёт **«Я закончил»** — мир, установленные моды/ресурспаки/датапаки и настройки сохраняются в облако.
4. Следующий человек забирает хостинг — приложение скачивает актуальный мир и запускает сервер уже у него, без ручного переноса файлов.

## Возможности

- **Учётные записи и друзья** — вход через Firebase Auth, список друзей, приватность списка серверов.
- **Синхронизация мира** — через Google Drive (OAuth) конкретного пользователя либо через общую сетевую папку; поддержка загрузки собственного мира.
- **Моды/ресурспаки/датапаки** — поиск и установка прямо из приложения через Modrinth API, с проверкой совместимости клиент/сервер и списком зависимостей («что понадобится»).
- **Настройки сервера** — режим игры, сложность, вайтлист, операторы, лимит игроков, ресурспак сервера и т.д. — редактируются создателем сервера прямо в лобби.
- **Модерация** — бан/кик по нику (офлайн-режим, UUID считается по стандартной формуле пиратского клиента), пароль на вход, скрытие сервера из общего списка.
- **Профиль** — аватар, ник, UID, список созданных и посещённых серверов.

## Технологии

- **.NET 8 / WPF** — интерфейс, без единого нативного popup-окна для основных сценариев (всё — встраиваемые UserControl'ы в одном окне).
- **Firebase** — Auth + Firestore, всё через прямые REST-запросы (без официального SDK).
- **Google Drive API v3 + OAuth2** — синхронизация файлов мира/сервера конкретного пользователя.
- **Modrinth API** — поиск и загрузка модов, ресурспаков, датапаков.

## Сборка

```powershell
dotnet build -c Release
```

Публикация self-contained однофайловой сборки:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

Установщик собирается через [Inno Setup](https://jrsoftware.org/isinfo.php) из `installer.iss`.

## Примечание про ключи в коде

В `Models/AppConfig.cs` зашиты API-ключ Firebase и Client ID/Secret для Google OAuth (desktop-приложение). Это осознанно и безопасно: ключи такого типа для desktop/mobile-приложений по дизайну Google не являются секретом (доступ ограничивается правилами безопасности Firestore и Drive-скоупом `drive.file`, а не секретностью самого ключа).
